ansmall-auth demo

JWT access tokens (15 min) + rotating refresh tokens (SHA-256 hash in SQLite). Passwords hashed with bcrypt. Gateway on :3000 proxies /api/* to auth on :3001.

Status: checking...

Credentials

Rate limit: 50 requests / 15 minutes per IP on register, login, refresh.

Session actions

Protected calls use Authorization: Bearer <accessToken>. Tokens live in localStorage (learning only).

API reference

Method Path Description
POST /api/register { email, password } → tokens + user
POST /api/login Same body and response as register
POST /api/refresh { refreshToken } → new access + rotated refresh
POST /api/logout { refreshToken } → revoke refresh token
GET /api/me Bearer access token → current user
